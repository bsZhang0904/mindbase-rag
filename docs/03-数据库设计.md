# 03 — 数据库设计

## 1. ER 关系概览

```
User 1───N KnowledgeBase 1───N Document 1───N DocumentChunk
  │              │
  │              └───────N Conversation 1───N Message
  │                                      │
  └──────────────────────────────────────┘
                              Message N───N DocumentChunk (citations)
```

---

## 2. 表结构

### 2.1 users — 用户

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 主键 |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 登录邮箱 |
| username | VARCHAR(64) | UNIQUE, NOT NULL | 显示名 |
| password_hash | VARCHAR(255) | NOT NULL | bcrypt |
| created_at | TIMESTAMPTZ | NOT NULL | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | 更新时间 |

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) NOT NULL UNIQUE,
    username VARCHAR(64) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

---

### 2.2 knowledge_bases — 知识库

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| user_id | UUID | FK → users.id | 所有者 |
| name | VARCHAR(128) | NOT NULL | 知识库名称 |
| description | TEXT | | 描述 |
| embedding_model | VARCHAR(64) | NOT NULL | 如 text-embedding-v3 |
| created_at | TIMESTAMPTZ | | |
| updated_at | TIMESTAMPTZ | | |

```sql
CREATE TABLE knowledge_bases (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(128) NOT NULL,
    description TEXT,
    embedding_model VARCHAR(64) NOT NULL DEFAULT 'text-embedding-v3',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_kb_user_id ON knowledge_bases(user_id);
```

---

### 2.3 documents — 文档

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| kb_id | UUID | FK → knowledge_bases.id | 所属知识库 |
| title | VARCHAR(255) | NOT NULL | 文件名/标题 |
| file_type | VARCHAR(16) | NOT NULL | pdf / md / txt |
| file_path | VARCHAR(512) | NOT NULL | 存储路径 |
| file_size | BIGINT | NOT NULL | 字节 |
| status | VARCHAR(16) | NOT NULL | pending/processing/ready/failed |
| error_message | TEXT | | 失败原因 |
| chunk_count | INT | DEFAULT 0 | 切块数量 |
| created_at | TIMESTAMPTZ | | |
| updated_at | TIMESTAMPTZ | | |

```sql
CREATE TYPE document_status AS ENUM ('pending', 'processing', 'ready', 'failed');

CREATE TABLE documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    kb_id UUID NOT NULL REFERENCES knowledge_bases(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    file_type VARCHAR(16) NOT NULL,
    file_path VARCHAR(512) NOT NULL,
    file_size BIGINT NOT NULL,
    status document_status NOT NULL DEFAULT 'pending',
    error_message TEXT,
    chunk_count INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_doc_kb_id ON documents(kb_id);
CREATE INDEX idx_doc_status ON documents(status);
```

---

### 2.4 document_chunks — 文档块（含向量）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| document_id | UUID | FK → documents.id | |
| kb_id | UUID | FK → knowledge_bases.id | 冗余，加速按库检索 |
| chunk_index | INT | NOT NULL | 文档内序号 |
| content | TEXT | NOT NULL | 块文本 |
| token_count | INT | | 估算 token 数 |
| page_number | INT | | PDF 页码（可选） |
| embedding | vector(1536) | NOT NULL | 维度随模型调整 |
| created_at | TIMESTAMPTZ | | |

```sql
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE document_chunks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    document_id UUID NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    kb_id UUID NOT NULL REFERENCES knowledge_bases(id) ON DELETE CASCADE,
    chunk_index INT NOT NULL,
    content TEXT NOT NULL,
    token_count INT,
    page_number INT,
    embedding vector(1536) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_chunk_document_id ON document_chunks(document_id);
CREATE INDEX idx_chunk_kb_id ON document_chunks(kb_id);

-- HNSW 向量索引（ cosine 相似度）
CREATE INDEX idx_chunk_embedding ON document_chunks
    USING hnsw (embedding vector_cosine_ops);
```

**检索 SQL 示例**：

```sql
SELECT id, document_id, content, page_number,
       1 - (embedding <=> :query_vector) AS score
FROM document_chunks
WHERE kb_id = :kb_id
ORDER BY embedding <=> :query_vector
LIMIT 8;
```

### 2.5 conversations — 对话会话

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| user_id | UUID | FK → users.id | |
| kb_id | UUID | FK → knowledge_bases.id | 绑定的知识库 |
| title | VARCHAR(255) | | 首条问题摘要 |
| created_at | TIMESTAMPTZ | | |
| updated_at | TIMESTAMPTZ | | |

```sql
CREATE TABLE conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    kb_id UUID NOT NULL REFERENCES knowledge_bases(id) ON DELETE CASCADE,
    title VARCHAR(255),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_conv_user_id ON conversations(user_id);
CREATE INDEX idx_conv_kb_id ON conversations(kb_id);
```

---

### 2.6 messages — 消息

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| conversation_id | UUID | FK | |
| role | VARCHAR(16) | NOT NULL | user / assistant |
| content | TEXT | NOT NULL | |
| created_at | TIMESTAMPTZ | | |

```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
    role VARCHAR(16) NOT NULL CHECK (role IN ('user', 'assistant')),
    content TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_msg_conv_id ON messages(conversation_id);
```

---

### 2.7 message_citations — 引用关联

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | |
| message_id | UUID | FK → messages.id | assistant 消息 |
| chunk_id | UUID | FK → document_chunks.id | |
| citation_index | INT | NOT NULL | [1][2] 编号 |
| score | FLOAT | | 检索相似度 |

```sql
CREATE TABLE message_citations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    message_id UUID NOT NULL REFERENCES messages(id) ON DELETE CASCADE,
    chunk_id UUID NOT NULL REFERENCES document_chunks(id) ON DELETE CASCADE,
    citation_index INT NOT NULL,
    score FLOAT,
    UNIQUE (message_id, citation_index)
);

CREATE INDEX idx_citation_message_id ON message_citations(message_id);
```

## 3. 索引策略总结

| 表 | 索引 | 用途 |
|----|------|------|
| knowledge_bases | user_id | 用户知识库列表 |
| documents | kb_id, status | 文档列表、任务监控 |
| document_chunks | kb_id + HNSW(embedding) | RAG 检索核心 |
| conversations | user_id | 历史会话 |
| messages | conversation_id | 对话加载 |

---

## 4. 数据隔离原则

所有查询必须满足：

```sql
-- 示例：检索 chunk 时
WHERE kb_id = :kb_id
  AND kb_id IN (SELECT id FROM knowledge_bases WHERE user_id = :current_user_id)
```

删除知识库时 `ON DELETE CASCADE` 级联删除 documents、chunks、conversations。
