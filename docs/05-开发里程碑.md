## W4 — Embedding + 向量入库

### 任务

- [ ] 启用 pgvector 扩展
- [ ] `document_chunks` 表 + HNSW 索引
- [ ] 实现 `Embedder`：调用 Embedding API（batch）
- [ ] ingest 流程串联：解析 → 切块 → embed → 批量 insert
- [ ] 错误处理：API 失败重试、document.status=failed

### 验收标准

```sql
SELECT COUNT(*) FROM document_chunks WHERE kb_id = '...';
-- 上传 1 份 PDF 后 count > 0

SELECT id, content, 1 - (embedding <=> :q) AS score
FROM document_chunks WHERE kb_id = :kb ORDER BY embedding <=> :q LIMIT 5;
-- 手动测相似度合理
```

### 关键参数

- Embedding 模型维度与 `vector(1536)` 一致
- batch_size: 16–32
