# MindBase 示例文档 — 可用于测试 RAG 问答

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合信息检索与大语言模型的技术架构。它在生成回答之前，先从知识库中检索相关文档片段，再将这些片段作为上下文提供给大语言模型，从而减少幻觉并提高回答的准确性。

## RAG 的核心流程

1. **文档 ingestion**：上传 PDF、Markdown 等文档，解析为纯文本。
2. **切块（Chunking）**：将长文本切分为较小的语义块，便于检索。
3. **向量化（Embedding）**：使用 Embedding 模型将文本块转换为高维向量。
4. **存储**：向量存入向量数据库（如 pgvector、Milvus）。
5. **检索（Retrieval）**：用户提问时，将问题向量化，检索 Top-K 最相似的文本块。
6. **生成（Generation）**：将检索到的文本块作为上下文，调用 LLM 生成回答。

## 引用溯源

好的 RAG 系统应该在回答中标注引用来源，让用户可以核对原文。MindBase 会在回答中使用 [1][2] 格式标注引用，并在侧边栏展示原文片段和页码。

## pgvector

pgvector 是 PostgreSQL 的向量扩展，支持存储和检索高维向量。它支持 IVFFlat 和 HNSW 索引，适合中小规模向量检索场景。

## 虚拟内存（测试用）

虚拟内存是操作系统中一种内存管理技术，它将物理内存和磁盘存储结合起来，为每个进程提供独立的地址空间。页表用于将虚拟地址映射到物理地址，缺页中断发生在访问的页面不在物理内存中时。
